# Moving to a New Device

## With a hamrs.app subscription

Use [HAMRS Sync](/docs/sync/setting-up-sync). On the new device's **First Time Setup** screen, follow the **Already have data?** link to the **Sync Page** and paste your API Key. Your profiles and logbooks are pulled down before you create anything new.

## Without a subscription

Move each logbook as an ADIF file.

1. On the old device, [export each logbook](./adif-export-import.md#exporting-a-logbook).
2. Copy the `.adi` files to the new device.
3. On the new device, complete First Time Setup, then use **Import Logbook** on the **Logbooks** page once per file. Pick the template the logbook used before.

An ADIF file holds QSOs only. Operator profiles and settings are not part of it, so set those up again on the new device.
