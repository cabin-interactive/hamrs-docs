# Activating Two Parks at Once

Each QSO in a POTA logbook carries one **My Park** reference. To get an ADIF file for each park from one set of contacts, log the activation once, then duplicate the logbook with the second park.

1. Log the whole activation in one POTA logbook, with the first park in **My Park**.
2. On the **Logbooks** page, open the logbook's menu and choose **Duplicate**.
3. Under **Bulk Update QSOs**, enter the second park in **My Park**. Change the title so you can tell the two logbooks apart, then click **Duplicate**.
4. Choose **Export ADIF** for each logbook.

You now have two files with the same contacts. Each has its own park in `MY_SIG_INFO`.

:::note
The copy keeps the My Grid and My State of the original logbook.
:::
