# QRZ Logbook API Key

:::info
The **QRZ Logbook API key** is for **uploading QSOs** from HAMRS to your QRZ Logbook. It requires a paid QRZ.com XML subscription.

Callsign lookups use a different credential: your QRZ.com username and password. See [Which credential is which](/docs/integrations/callsign-lookups#which-credential-is-which).
:::

## Finding your API Key on QRZ.com

### 1. Navigate to your Logbook Settings:

![QRZ Logbook Settings Button](./img/qrz-logbook-settings.png)

### 2. Click 'Show' to un-hide your API key:
![QRZ Show API Key](./img/qrz-show-api-key.png)

### 3. Enter your API Key in HAMRS Config > Integrations:

![HAMRS QRZ API Key input](./img/hamrs-qrz-api-key-input.png)

Once the key is saved, you can [upload a logbook to QRZ](./uploading-logbooks).
